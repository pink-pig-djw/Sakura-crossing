# 桜ヶ浜 · Sakura Crossing

一个可以在浏览器里自由散步的日本海边小镇。动画背景感的非写实渲染（NPR）、治愈系的日常氛围：樱花坡道、电线杆与电线、商店街、樱花河畔、站前商业街和地铁站、单线小电车和踏切、海堤、沙滩、防波堤灯塔，还有远处的富士山。

An explorable anime-background-style Japanese seaside town in spring, built with Three.js. Everything — houses, signs, trees, clouds, sea, sounds and music — is generated procedurally at load time; the only recorded assets are the Japanese voice lines (synthesized with VOICEVOX).

**在线试玩 / Play online：<https://pink-pig-djw.github.io/Sakura-crossing/>**

界面可在 **日本語 / 中文** 之间切换（标题画面或菜单里的「语言」），浏览器语言为中文时默认显示中文。想直接分享中文版，可以用 <https://pink-pig-djw.github.io/Sakura-crossing/?lang=zh>。

## 运行 / Run

```bash
npm install
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 产出 dist/，可部署为静态网站
npm run preview  # 本地预览 dist/
npm run deploy   # 构建并把 dist/ 发布到 gh-pages 分支（GitHub Pages）
```

需要支持 WebGL2 的浏览器（桌面版 Chrome / Edge / Firefox / Safari，或较新的手机浏览器）。

## 小镇里有什么

- **桜坂**：从山上神社一路通向海边的樱花坡道，两侧是带阳台晾衣、空调外机、电视天线、砖墙和停车位的住宅。
- **浜通り商店街**：和果子店、喫茶店、杂货店、面包房、花店、鱼店、拉面店、驼菓子屋……挂着灯笼和「さくらまつり」旗子，入口有拱门。
- **桜ヶ浜駅**：站房、检票口、站台、駅名標、时刻表、自贩机；两节编组的奶油色电车按时刻进出站，经过三处踏切时栏杆放下、红灯交替闪烁、「カンカン」作响。站在轨道上电车会停下鸣笛。
- **海岸**：海岸通り、带棕榈树的海堤步道、下到沙滩的台阶、防沙竹篱、渔船、防波堤与消波块、白色灯塔；海面有浪花、涌上沙滩的白沫、阳光下的粼粼波光，远处有小岛、帆船和富士山。
- **桜川**：石砌护岸的小河从山脚的涵洞流出，穿过小镇流进海里。两岸是樱花步道、雪洞灯笼和长椅，河里有落差工（小瀑布）和顺流漂着的花筏；可以从台阶下到河边、踩着「飛び石」过河，也可以走朱红栏杆的**桜橋**、**汐見橋**、**河口橋**等桥。
- **西町**：小镇西侧扩建的住宅坡地，独栋住宅、老式木造房屋、公寓、菜园和月租停车场交错。
- **桜ヶ浜中央**（站前商业区）：带行道树和杜鹃花坛的大道、红绿灯与盲人提示音、公交站、写字楼和杂居楼。可以进去逛的室内：
  - **さくらマート**（便利店）：自动门开门铃声、饮料冷柜、饭团、杂志、收银台和咖啡机；
  - **喫茶 さくらテラス**：河边露台和店内的座位；
  - **さくらモール**：两层商场，中庭有天窗和樱花树，楼梯 / 扶梯、可丽饼摊、扭蛋机、美食广场；
  - **市立図書館**、**中央広場**（喷泉、花坛、钟楼）。
- **地铁 桜ヶ浜中央駅**：两个出入口 → 地下一层的售票机和闸机 → 地下二层的岛式站台，站台门与列车门同步开关，列车按时进出站，有到站提示音。
- **ひだまり公園**、**汐の湯**（钱汤和烟囱）、**汐見神社**（石阶、鸟居、拝殿、狛犬、绘马、俯瞰小镇的长椅）。
- 7 只可以摸的猫、8 枚散落在沙滩上的贝壳、能买到 10 种饮料的自动贩卖机（偶尔会中奖再来一瓶）、5 种签运的御神签。

## 镇上的人：春香

桜坂东侧的人行道上，有一位每天散步的居民「春香」（目前是一个原型角色）：

- **动作来自真人动作捕捉**：走路、鞠躬、挥手、点头、指路都来自万代南梦宫研究所公开的动作捕捉数据（女性风格），用 `tools/anim/retarget.mjs` 重定向到 VRM 人物的骨骼上。动捕骨骼的关节坐标轴和 VRM 不同，所以每块骨骼先在一帧自然站姿上做校准，再逐帧换算；走路剪成一个无缝的步态循环，移动速度和脚步严格匹配，不会「滑步」。
- **叠加的细节**：呼吸起伏、头和眼睛转向你（VRM 视线）、随机眨眼（偶尔连眨两下）、开心时的表情、说话时按语音音量动嘴、头发和衣服的物理摆动（VRM spring bone），以及在坡道上用双骨骼 IK 让两只脚各自踩在地面上。
- **行为**：在人行道上来回散步，经过行道树时会往路边让一让；你靠近时停下来看着你、转身面对你，走到两三米内会鞠躬说「あ、こんにちは。」；按 E 和她聊天（点头、或者转身为你指向海边）；你离开时挥手说「またね」。配音为 VOICEVOX:四国めたん。
- **画风统一**：人物不用模型自带的 MToon 着色，而是用小镇同一套卡通光照（硬明暗交界、按材质的阴影色、细轮廓光、大气透视、描边），所以早晨、傍晚、夜里都和场景一致。

## 小地图与语言

- 右上角的圆形小地图随朝向旋转（前方朝上），边缘的「N」指示北方；画出道路、地块、河流、铁路、地铁出入口和主要地名，地名会自动避让、不遮挡玩家箭头。`N` 键 / 手柄 `View` 键 / 菜单里可以关闭。
- 界面文字（标题、菜单、提示、地名横幅、地图标注、调查结果、御神签、字幕）都有简体中文版本；街上的招牌、站名牌等「町里的东西」保持日文。

## 渲染风格 / Rendering

- **卡通着色**：自定义 `ShaderMaterial`（接入 three.js 的阴影），硬明暗交界线 + 偏紫蓝的阴影色 + 交界处的暖色带，模仿动画背景的上色方式。
- **程序化表面细节**：外墙挂板、瓦片、水泥砌块、砖、沥青、沙、草地上的小花等都在着色器里按世界坐标生成，并做了抗锯齿与远处淡出。
- **描边**：后处理中对深度做拉普拉斯检测，只在靠近相机的一侧画线，线色是底色的加深版，并随距离淡出。
- **天空**：渐变天空 + 刷痕状卷云 + 程序化绘制的平底积云贴片（受时间段光照影响）+ 远山与富士山剪影 + 星空和月亮。
- **大气透视、泛光、镜头光晕、暗角、颗粒、分离色调**，以及 three.js r186 的 `SunLight` 级联阴影。
- 昼夜循环（默认 1 分钟 = 1 小时）：夜里窗户、路灯、自贩机、灯笼会亮，地面有光圈。
- **绿化**：树冠、树篱、灌木、花坛共用一套朝向相机的叶片卡片（Canvas 现场绘制的叶子 / 五瓣樱花 / 杜鹃花），树篱是叶片包裹的暗色内层，不再是绿色方块；草坪、路边、铁道边坡和山脚长着随风摆动的草丛（按 32 m 分块实例化，只绘制镜头附近）。树冠会自动避开建筑。

## 碰撞与「不穿模」

- 2D 空间哈希碰撞 + 可分层的行走面（桥面、站台、地下一二层、商场二楼可以上下叠放，按脚的高度判定所在楼层）。
- 河堤顶、桥头、踏切的抬高路面、飞石都有对应的行走面；不能下到有护岸的河道里涉水（河口沙滩处可以）。
- 电车车身、海岸路上的汽车、放下的踏切栏杆都是会移动的碰撞体；站在轨道或车道上，电车和汽车会停下。
- 停在坡上的车按四个轮子的位置倾斜，自动贩卖机、太阳能板、墙头的猫都贴合各自的表面。
- 坡地上的建筑：公寓的外楼梯、走廊立柱、房屋的雨水管、汐の湯的门廊柱、铁栅栏（带混凝土基座）都从各自位置的地面往上长，不会因为地基比地面高而悬空。
- 悬空自检：地址加 `?audit` 会记录所有长方体和圆柱，页面里的检查脚本能列出「底部离地、下面又没有东西托着」的立柱 / 栏杆 / 墙段（调试用，默认关闭）。
- 自动化测试脚本（Playwright）模拟玩家走进便利店 / 咖啡馆 / 图书馆 / 商场二楼、下地铁到站台、踩飞石过河、过每一座桥，用来检查卡住和掉落。

## 声音 / Audio

环境声全部用 Web Audio 合成：海浪、河水与落差工的水声、风、麻雀、树莺（ホーホケキョ）、海边的黑鸢（ピーヒョロロ）、夜晚的蛙鸣、风铃、踏切警报、红绿灯的盲人提示音（ピヨピヨ / カッコー）、便利店开门铃、地铁广播与到站旋律、电车（行驶声、轨缝声、鸣笛、发车旋律）、脚步声（沥青 / 沙 / 浅水），以及基于「王道进行」（IV–V–iii–vi）的生成式钢琴背景音乐。进入室内或地下时环境声会变闷。

### 日语配音

25 句日语女声由 [VOICEVOX](https://voicevox.hiroshiba.jp/) 合成（九州そら、冥鳴ひまり、春日部つむぎ），每种场景有自己的声音处理：

| 场景 | 什么时候 | 声音 |
| --- | --- | --- |
| 桜ヶ浜駅 | 电车接近（按行驶方向播「花見台行き / 汐風行き」）、到站、发车旋律后关门 | 站台喇叭：限频、两个喇叭的时间差、混响，声源在站台 |
| 地下铁 桜ヶ浜中央駅 | 1 / 2 号线列车接近、开门、关门，以及不定时的安全提示 | 地下站台喇叭，混响更长 |
| さくらマート | 进门「いらっしゃいませー！」、收银台、离开时「ありがとうございましたー！」 | 店员在柜台后，带一点房间声 |
| 喫茶店 / 可丽饼 / 图书馆 | 进店招呼、点单、借书 | 同上 |
| 自动贩卖机 / 售票机 | 买饮料、中奖、买票 | 小喇叭音色 |
| さくらモール | 在商场里时不定时的馆内广播 | 商场喇叭 |
| 町内广播 | 游戏时间到下午 5 点时，一段原创报时旋律后播放「よい子のみなさんは……」 | 远处喇叭在山间的回声 |
| 商业区红绿灯 | 偶尔在变绿时提示「青になりました」 | 小喇叭 |

说话时背景音乐会自动压低；屏幕下方显示字幕（随界面语言显示日文或中文，菜单里可关闭），语音音量单独可调。台词、说话人和语气预设在 `tools/voice/lines.json`，用 `tools/voice/generate.py`（VOICEVOX CORE 0.17）重新生成 `public/voice/*.mp3` 和 `src/systems/voiceLines.js`。

## 目录结构

```
src/
  main.js              游戏循环、交互、模式切换
  core/                几何合批 (builder.js)、随机与噪声
  render/              着色器、材质、天空、云、后处理管线、招牌贴图集
  world/               地形与布局、道路、房屋、商店街/车站/公园/神社、铁路与电车、海岸、
                       河流 (river.js)、商业区 (commercial.js)、地铁 (subway.js)、室内 (interiors.js)、
                       树与绿化 (trees.js / greenery.js / grass.js)、碰撞 (collision.js)、猫与鸟
  systems/             第一人称控制、手柄、昼夜、音频；配音播放 (voice.js) 与触发 (townVoices.js)；VRM 人物 (character.js)
  world/residents.js   居民「春香」的行为
  ui/                  界面、地图与小地图 (ui.js)、语言切换 (i18n.js) 与中文文本 (zh.js)
public/voice/          VOICEVOX 生成的配音（MP3）
public/chars/          人物模型（VRM）和重定向后的动作数据
tools/anim/            动捕 BVH → VRM 的重定向工具
tools/chars/           VRM 模型瘦身脚本
tools/voice/           配音台词表与生成脚本
tools/deploy-pages.sh  发布到 GitHub Pages
```

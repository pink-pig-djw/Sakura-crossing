# 桜ヶ浜 · Sakura Crossing

一个可以在浏览器里自由散步的日本海边小镇。动画背景感的非写实渲染（NPR）、治愈系的日常氛围：樱花坡道、电线杆与电线、商店街、单线小电车和踏切、海堤、沙滩、防波堤灯塔，还有远处的富士山。

An explorable anime-background-style Japanese seaside town in spring, built with Three.js. Everything — houses, signs, trees, clouds, sea, sounds and music — is generated procedurally at load time; there are no image, model or audio assets.

## 运行 / Run

```bash
npm install
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 产出 dist/，可部署为静态网站
npm run preview  # 本地预览 dist/
```

需要支持 WebGL2 的浏览器（桌面版 Chrome / Edge / Firefox / Safari，或较新的手机浏览器）。

## 小镇里有什么

- **桜坂**：从山上神社一路通向海边的樱花坡道，两侧是带阳台晾衣、空调外机、电视天线、砖墙和停车位的住宅。
- **浜通り商店街**：和果子店、喫茶店、杂货店、面包房、花店、鱼店、拉面店、驼菓子屋……挂着灯笼和「さくらまつり」旗子，入口有拱门。
- **桜ヶ浜駅**：站房、检票口、站台、駅名標、时刻表、自贩机；两节编组的奶油色电车按时刻进出站，经过三处踏切时栏杆放下、红灯交替闪烁、「カンカン」作响。站在轨道上电车会停下鸣笛。
- **海岸**：海岸通り、带棕榈树的海堤步道、下到沙滩的台阶、防沙竹篱、渔船、防波堤与消波块、白色灯塔；海面有浪花、涌上沙滩的白沫、阳光下的粼粼波光，远处有小岛、帆船和富士山。
- **ひだまり公園**、**汐の湯**（钱汤和烟囱）、**汐見神社**（石阶、鸟居、拝殿、狛犬、绘马、俯瞰小镇的长椅）。
- 7 只可以摸的猫、8 枚散落在沙滩上的贝壳、能买到 10 种饮料的自动贩卖机、5 种签运的御神签。

## 渲染风格 / Rendering

- **卡通着色**：自定义 `ShaderMaterial`（接入 three.js 的阴影），硬明暗交界线 + 偏紫蓝的阴影色 + 交界处的暖色带，模仿动画背景的上色方式。
- **程序化表面细节**：外墙挂板、瓦片、水泥砌块、砖、沥青、沙、草地上的小花等都在着色器里按世界坐标生成，并做了抗锯齿与远处淡出。
- **描边**：后处理中对深度做拉普拉斯检测，只在靠近相机的一侧画线，线色是底色的加深版，并随距离淡出。
- **天空**：渐变天空 + 刷痕状卷云 + 程序化绘制的平底积云贴片（受时间段光照影响）+ 远山与富士山剪影 + 星空和月亮。
- **大气透视、泛光、镜头光晕、暗角、颗粒、分离色调**，以及 three.js r186 的 `SunLight` 级联阴影。
- 昼夜循环（默认 1 分钟 = 1 小时）：夜里窗户、路灯、自贩机、灯笼会亮，地面有光圈。

## 声音 / Audio

全部用 Web Audio 合成：海浪、风、麻雀、树莺（ホーホケキョ）、海边的黑鸢（ピーヒョロロ）、夜晚的蛙鸣、风铃、踏切警报、电车（行驶声、轨缝声、鸣笛、发车旋律）、脚步声（沥青 / 沙 / 浅水），以及基于「王道进行」（IV–V–iii–vi）的生成式钢琴背景音乐。

## 目录结构

```
src/
  main.js              游戏循环、交互、模式切换
  core/                几何合批 (builder.js)、随机与噪声
  render/              着色器、材质、天空、云、后处理管线、招牌贴图集
  world/               地形与布局、道路、房屋、商店街/车站/公园/神社、铁路与电车、海岸、树、猫与鸟
  systems/             第一人称控制、昼夜、音频
  ui/                  界面与地图
```

# 桜ヶ浜 · Sakura Crossing

一个可以在浏览器里自由散步的日本海边小镇。动画背景感的非写实渲染（NPR）、治愈系的日常氛围：樱花坡道、电线杆与电线、商店街、樱花河畔、站前商业街和地铁站、单线小电车和踏切、海堤、沙滩、防波堤灯塔，还有远处的富士山；骑上自行车，还能沿着绕山一圈的「さくら一周ライン」骑过渔港、蜜柑园、风车之丘、茶园、千本鸟居、梯田、竹林、手凿隧道和海岬灯塔再回到海边。天气也会变：下雨的时候，主角会撑起一把透明伞。

An explorable anime-background-style Japanese seaside town in spring, built with Three.js. Everything — houses, signs, trees, clouds, sea, sounds and music — is generated procedurally at load time; the only recorded assets are the Japanese voice lines (synthesized with VOICEVOX).

**在线试玩 / Play online：<https://pink-pig-djw.github.io/Sakura-crossing/>**

界面可在 **日本語 / 中文** 之间切换（标题画面或菜单里的「语言」），浏览器语言为中文时默认显示中文。想直接分享中文版，可以用 <https://pink-pig-djw.github.io/Sakura-crossing/?lang=zh>。

## 运行 / Run

```bash
npm install
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 产出 dist/，可部署为静态网站
npm run preview  # 本地预览 dist/
npm run deploy   # 构建并把 dist/ 发布到 gh-pages 分支（GitHub Pages）
```

需要支持 WebGL2 的浏览器（桌面版 Chrome / Edge / Firefox / Safari，或较新的手机浏览器）。

靠近电车时手柄会轻微震动（支持震动的浏览器）。

## 小镇里有什么

- **桜坂**：从山上神社一路通向海边的樱花坡道，两侧是带阳台晾衣、空调外机、电视天线、砖墙和停车位的住宅。
- **浜通り商店街**：和果子店、喫茶店、杂货店、面包房、花店、鱼店、拉面店、驼菓子屋……挂着灯笼和「さくらまつり」旗子，入口有拱门。12 家店都可以走进去（坡上的店门口有台阶），每家的店内各不相同（见下面的「商店」）。
- **桜ヶ浜駅**：站房、检票口、站台、駅名標、时刻表、自贩机；两节编组的奶油色电车按时刻进出站，经过各处踏切时栏杆放下、红灯交替闪烁、「カンカン」作响。轨道上有人（主角或芽衣）时，电车会提前用常用制动减速、停在几米外鸣笛，来不及时改用紧急制动，无论如何都不会碰到人；打开菜单或地图时也一样。
- **海岸**：海岸通り、带棕榈树的海堤步道、下到沙滩的台阶、防沙竹篱、渔船、防波堤与消波块、白色灯塔；海面有浪花、涌上沙滩的白沫、阳光下的粼粼波光，远处有小岛、帆船和富士山。
- **桜川**：石砌护岸的小河从山脚的涵洞流出，穿过小镇流进海里。两岸是樱花步道、雪洞灯笼和长椅，河里有落差工（小瀑布）和顺流漂着的花筏；可以从台阶下到河边、踩着「飛び石」过河，也可以走朱红栏杆的**桜橋**、**汐見橋**、**河口橋**等桥。
- **西町**：小镇西侧扩建的住宅坡地，独栋住宅、老式木造房屋、公寓、菜园和月租停车场交错。
- **桜ヶ浜中央**（站前商业区）：带行道树和杜鹃花坛的大道、红绿灯与盲人提示音、公交站、写字楼和杂居楼。可以进去逛的室内：
  - **さくらマート**（便利店）：自动门开门铃声、饮料冷柜、饭团、杂志、收银台和咖啡机；
  - **喫茶 さくらテラス**：河边露台和店内的座位；
  - **さくらモール**：两层商场，中庭有天窗和樱花树，楼梯 / 扶梯、可丽饼摊、扭蛋机、美食广场；两层共 18 家专卖店都换成了透明玻璃门面，可以走进去；
  - **市立図書館**、**中央広場**（喷泉、花坛、钟楼）。
- **地铁 桜ヶ浜中央駅**：两个出入口 → 地下一层的售票机和闸机 → 地下二层的岛式站台，站台门与列车门同步开关，列车按时进出站，有到站提示音。
- **東町**（商业区东侧新扩建的街区，有自己的踏切和通往东边隧道的海岸路）：
  - **桜ヶ浜高校**：四层教学楼可以从校门、昇降口（换室内鞋）一路走到屋顶——走廊、折返楼梯、1〜3 年级各 6 个教室（2 年 B 组的黑板上写着「日直 桜井・春野」，可以坐窗边最后一排）、职员室、保健室、图书室、学生会室、广播室、音乐室（钢琴）、美术室、理科室；屋顶有铁丝网、水塔、长椅和大钟。穿过连廊进**体育馆**（球场线、篮筐可以投篮、舞台与幕布）；后院的台阶上去是带 200 m 跑道的**操场**（球门、朝会讲台、单杠、沙坑、器材仓库）。
  - **桜ヶ浜総合病院**：自动门、总服务台与收费处、候诊长椅、诊室门、取药窗口的叫号屏、小卖部、电梯、楼层导览；门口有出租车停靠的雨棚、救护车和急诊入口、停车场和「総合病院前」公交站。
  - **桜ヶ浜郵便局**（窗口、ATM、门前台阶和红色邮筒）、**交番**（可以问路）、药店、面包房和一片住宅。
- **商店**：商店街、商场和站前写字楼一楼一共 **81 家店可以走进去**（站前的店有自动门），店内都是立体建模、按店的种类各自布置，不是同一个模板换颜色——和果子店的玻璃柜里一盘盘樱饼和草团子、身后的礼盒架和红毡长凳；喫茶的吧台、虹吸壶、唱机和吊灯；面包房的托盘与夹子；花店的阶梯花桶和鲜花冷柜；鱼店倾斜的冰台；拉面店的食券机和汤锅；驼菓子屋的玻璃罐和抽签条；理发店的理发椅；洗衣店挂着的一排塑料袋衬衫；书店、服装店的衣架与假人、运动用品的鞋墙和球筐、眼镜店的镜框墙、玩具店的大熊和火车模型、家电店的电视墙、宠物店的玻璃小屋、夹娃娃机、毛线格子、牛丼的马蹄形吧台、烤肉的排烟罩、和食的榻榻米座位、投币洗衣机……地板、墙色和灯光也按店的种类不同。每家店里都可以按 E（有的还能坐下），会有各自的一句话。站前一楼的店是从 20 种店里轮流分配的，同一种店再次出现时换另一种布局。
- **室内家具是立体建模的**：书架上的书一本本立着（成套的颜色和高度、偶尔空一格、平放的一摞、书立，图书馆的书脊贴着索书号标签），学生会室是文件夹、广播室是 CD；便利店和医院小卖部的货架上是瓶装饮料、罐装、杯面、零食袋、饭团、便当、布丁和挂着的卡片，杂志架上有封面；储物柜是一扇扇门（钱汤是木门、铜号码牌和木头钥匙，学校鞋柜是开放格子里的室内鞋和运动鞋，教室后面是放书包的格子），邮局里有带触摸屏的「宅配ロッカー」。这些东西（连同商店的内装）只在 55 m 内绘制，不增加街景的负担。
- **汐の湯**（钱汤，现在可以进去）：门口的下足箱、前台和价目表、挂钟、长椅、按摩椅、装满咖啡牛奶的冷柜；挂着「女」字暖帘的一侧是更衣室（木头储物柜、梳妆台和吹风机、体重秤、电风扇），隔着玻璃门是浴室——瓷砖墙、一排排水龙头、圆凳和黄色水桶、浴池，墙上画满富士山和大海。男汤那侧挂着「清掃中」的牌子。
- **ひだまり公園**、**汐見神社**（石阶、鸟居、拝殿、狛犬、绘马、俯瞰小镇的长椅）。
- 7 只可以摸的猫、8 枚散落在沙滩上的贝壳、能买到 10 种饮料的自动贩卖机（偶尔会中奖再来一瓶）、5 种签运的御神签。

## 主角：桜井ななみ（第三人称）

默认用第三人称视角，镜头在主角「桜井ななみ」身后（`V` 键、手柄按下右摇杆或菜单里可以切回第一人称）：

- **跟着你走**：她朝移动方向转身；站着时待机，走路和奔跑的动作按实际速度播放（脚步和地面严格同步，脚步声也跟着她的步幅）；跳起来时是腾空的动作，从高处落下时是下落的动作；在长椅和座位上会坐下（并膝、手放在腿上），镜头转到她斜前方。
- **头会转向**：她会看向你镜头所看的方向，靠近可以调查的东西或芽衣时会看向它们。
- **上下楼梯**：走到台阶上（学校楼梯、神社石阶、海边台阶、车站门口等）会换成 Mixamo 的上楼 / 下楼 / 跑上楼动作——身体沿着台阶连成的斜线平滑上升，抬腿高度按实际台阶高度缩放，两只脚由 IK 一级一级踩在台阶面上；在楼梯上每秒大约走三级（跑起来五级），脚步声也一级一响。坡道和单个路缘石不会被当成楼梯。
- **神社参拜**：在神社按 E 时，她会面向本殿双手合十、低头闭眼祈祷（约 3 秒），然后才弹出御神签。原动作（Mixamo 的 Praying）祈祷时上身后仰、抬头，转换时按后仰的幅度改成了前倾低头（`bow` 选项），更接近日本神社的参拜习惯。
- **五套服装**（哥特风的外裙从腰部撑开，穿它时自然下垂的手臂会稍微向外张开，手落在裙摆外面；所有裙摆的物理骨骼都会避开腿、前臂和手）：连衣裙、连帽衫、校服、牛仔短裤（白色蕾丝挂脖短上衣 + 做旧牛仔短裤 + 红白高帮鞋）、哥特风（金色刺绣的黑色连衣裙、项圈、单边过膝袜和短靴），在菜单「ななみの服装」里随时更换（每套第一次穿时才加载，之后切换是即时的），选择会被记住。
  在 VRoid 里只改了一套的体型时（比如胸部参数），可以用 `tools/chars/transfer_shape.py 改之前.vrm 改之后.vrm 其他服装.vrm 输出.vrm` 把同样的变化（骨骼位置、物理参数和身体与衣服的形状）搬到其他服装上。
- **镜头**：鼠标滚轮调整远近；碰到墙、柱子、房间的天花板、上一层的地板（地铁站、商场二楼）时自动拉近，离开后缓缓退回；镜头贴近到会穿进人物时，人物暂时隐藏。
- **皮肤在阴影里不会发黑**：人物的阴影面有一个下限（不低于受光面的约八成），并带一点皮肤自身的暖色，所以在树荫、楼影里也是明亮的动画肤色。

## 桜井家（ななみ的家）

ななみ一个人住在桜坂东侧的一栋两层小楼里（游戏开始的地方往东走几步就是她家的院门，开局仍在外面的坡道上）。在地图上按「家に帰る」可以直接回到院门口（坐船或骑车时要先下来）。

- **外面**：贴瓷砖的门柱上挂着「桜井」的门牌，带摄像头的对讲机和信箱，门柱上的小灯；砖墙和矮树篱围着的前院里有一棵小樱树、一排开花的灌木、踏脚石和花盆；自行车棚是透明的雨棚；门廊上方有雨檐和筒灯，二楼有阳台和晾衣杆，屋顶是双坡瓦顶，外墙有空调外机、电表、雨水管和楼层之间的腰线。
- **一楼**：玄关的土间（瓷砖地、鞋柜上摆着花和钥匙盘、伞架、另一双鞋、在台阶上等着的拖鞋），踏上「上がり框」就是走廊；**和室**是 6 张榻榻米的「祝儀敷き」（没有四角相交的接缝，草席纹理和布边都做出来了），床之间挂着樱花挂轴、插着一枝樱花，有箪笥、矮桌上的茶具和三色团子、两个座布团、行灯、窗内的障子，和客厅之间是两扇拉到一边的隔扇（两面都裱着纸、带圆形拉手）；**LDK** 有厨房（吊柜、抽油烟机、薄荷色冰箱和冰箱贴、电热水壶和茶具）、餐桌和吊灯、沙发和抱枕、电视柜、落地灯、窗帘（纱帘拉到一边，能看到院子），以及通往二楼的楼梯（扶手、栏杆柱、楼梯下的收纳门）。
- **二楼**：她的卧室——床头柜和台灯、床上的兔子玩偶、窗边的书桌（书、笔筒、仙人掌、台灯、软木板和照片）、衣柜（里面挂着她五套衣服的颜色）和穿衣镜、书架、「ほしぞら」海报、日历（翻到今天的日期，见下面的「日期」）、挂钟、空调、窗边一串小彩灯；落地窗外是阳台。
- **灯光**：白天是窗外的日光；天黑以后她在家时房间亮起暖色的灯，不在家时是暗下来的房子；睡觉时灯会调暗。

## 作息：困了就回家睡觉

小镇的时钟只会往前走：时间自己流逝、在菜单或 `T` 键切换时间段（会走到下一次到达那个钟点，跳过的时间也算）、睡觉，都会让它前进。按这个时钟：

- **起床后 8 小时内睡不着**：躺到床上只会休息一会儿，并提示还要多久才能睡。
- **睡多久取决于有多累**：醒着的时间的一半，最少 30 分钟、**最多 8 小时**（取整到 5 分钟），床的提示会写「眠る（約○時間○分）」。
- **醒着超过 20 小时会疲劳**：走路变慢、跑不快（换成疲惫的走路动作）、时不时打哈欠或揉脖子、眼皮发沉，时钟下面出现「眠い」的提示，直到睡一觉。
- **睡觉时**：屏幕暗下来，时钟一路走到起床的时刻，天气也会跟着过去这几个小时（中间开始或停止的雨、地面湿不湿），然后天亮醒来。
- 菜单里的散步手帐会显示「起床后○小时○分」和在床上睡过几次。

动作来自 Mixamo（躺下、躺着、睡着、跪坐、写字、喝水、开门、坐着笑 / 打瞌睡、疲惫地走、伸展脖子等），只有主角用的这些放在 `public/chars/motions_own.json`，换衣服时一起加载。

- **时钟旁边**显示日期：「4月10日（金）」/「4月10日 周五」，换日的时候日期会亮一下；窄屏（手机竖屏）上缩成「4/10（金）」放在时间下面。

## 自行车

按 `B`（手柄十字键上、手机右下「自行车」）就能骑上ななみ的自行车——一辆日本街头最常见的「ママチャリ」（买菜车）：

- **车本身**：低跨点的 U 形车架（亮面烤漆，有一道干净的高光）、向后弯的镀铬车把和皮质握把、刹车把和走线、左手边的车铃、右手边的三速转把，前面是钢丝车筐，筐下挂着车灯；前后挡泥板、整片包住链条的链罩、后货架和反光片、后轮锁、带弹簧的皮座、两脚停车架。车轮是 32 根交叉编法的辐条、镀铬轮圈和轮毂（前轮是发电花鼓、后轮是内变速花鼓和滚筒刹车），踏板带黄色反光片。镀铬部分会映出天空和地面、太阳下闪一下光。座高和车把高度按她的骨骼算出来：脚踩到最低时腿伸直约 93%，手臂微弯握住车把。
- **四种颜色**：薄荷绿、樱花粉、奶油色（配焦糖色轮胎侧壁和藤编风车筐）、藏青，在菜单「自行车の色」里换，会被记住。
- **调速**：三个挡位（`Q` / `E` 或数字键 `1` `2` `3`，手柄 `LB` / `RB`），平路上分别大约 12 / 17 / 23 km/h；按住 `Shift`（手柄 `RT`）站起来蹬，加速更猛、最高再快约两成；摇杆推得浅就骑得慢。右上角显示当前挡位和时速。
- **骑起来的感觉**：上坡会慢下来（坡道上用 3 挡起步会很吃力，换 1 挡就轻松了，起步和爬坡时她会自动站起来蹬），下坡会越滑越快；不蹬时滑行，听得到飞轮「嗒嗒嗒」的声音；`S` 刹车，停稳后继续按住会用脚推着车慢慢后退；转弯时车身会向内倾斜，车把跟着转；在沙滩上骑会很费力。撞到墙时如果只是擦过会顺势偏开，正面撞上才停下。
- **她在车上**：坐在车座上微微前倾，双脚由 IK 踩在踏板上随曲柄转动，双手握住握把（手指包住握把，会跟着车把转向）；站起来蹬时身体左右摇；停下时左脚放到地上、车身略微倾向那一侧；她会看着前方的路、转弯时看向弯道（你转动视角时会看向你看的方向），速度越快笑得越开心，头发随风向后飘。连衣裙和校服的裙摆在骑车时会随膝盖上下摆动，盖住大腿，不会穿模。
- **上下车**：车会出现在她右手边，她跨上去；下车时站到车的左侧，车用停车架立在原地、车把歪向一边。如果停下的地方车身一半在路缘或坡道边上（一个轮子在上、一个在下，或者停车架悬空），她会先把车往前、往后或往旁边推一小段，推到平整的地方再停好；叫车过来时也只会放在平整的地方。走开后再按 `B`，如果车就在附近会骑回那辆，离得远就把车叫到身边；停着的车在小地图上有标记，也挡路（别人会绕开）。
- **不能骑的地方**：台阶和楼梯（两级以上的台阶）、高于约 21 cm 的路缘、室内（店门口会提示「骑着自行车进不去」）、地下、河里和海里。海堤步道比车道高 32 cm，在每个下沙滩的台阶旁边新加了一段带黄色盲道砖的**无障碍坡道**，可以骑上去沿海边骑。
- **路上的人**：路人会提前避让骑车的她，前面有人时她会自动减速；按 `Space`（手柄 `X`）响车铃「叮铃叮铃」，附近的路人会回头看，前面走路的人会靠边让路几秒。
- **夜里**：车灯会自动亮起，在前方路面上照出一片暖色的光，后面的反光片发红光。
- **声音**：轮胎压过路面的声音（随速度变高）、滑行时飞轮的嗒嗒声、风声、急刹车时的刹车尖声、换挡的咔嗒声、踢起停车架的声音、链条声和车铃，全部是程序合成的。
- **镜头**：骑车时镜头离得稍远，不动鼠标时会慢慢转回车的正后方；速度快时视角会略微变宽。第一人称时从车座上看出去，看得到车筐和车把。

## 小船与大海（さくら桟橋・凪ノ島）

**不会掉进水里**：所有水边（栈桥、浮栈桥、渔港岸壁、防波堤、楼梯、河岸和飞石）都有看不见的墙，走过去或跳过去都下不去；从沙滩只能走进脚踝深的浪花里。万一因为别的原因站进了深水，她会马上回到最后站过的干地方。

从桜坂下面的海滩台阶往海里伸出一座木栈桥 **さくら桟橋**：白色栏杆、提灯样式的路灯，尽头是 T 字形的平台，有长椅、「ボート乗り場」小屋和救生圈。平台东侧的楼梯下到**浮栈桥**，她的小船「さくら丸」就系在那里。

- **上船**：走到浮栈桥上按 `E`（手柄 `A`、手机「しらべる」）。她会先沿浮栈桥走到船尾座位旁边，跨过船舷踩到船底板上，转身坐到船尾的横座上，右手握住舷外机的舵柄，左手放在膝上。
- **开船**：`W` 前进、`S` 后退、`A` / `D` 转舵，按住 `Shift` 全速（手柄：左摇杆，`RT` 全速；手机：摇杆，「全速」按钮）。平常约 20 km/h，全速约 23 km/h；船速越快船头抬得越高，转弯时船身向内倾，停下时随着涌浪轻轻起伏。舷外机会随转舵摆动，螺旋桨在转。右上角显示油门和航速。
- **靠岸**：开到栈桥或码头旁边、放慢到步行速度，按 `E` 就会自动靠上去、系好缆绳，她站起来跨回岸上。速度太快或附近没有能靠的地方会提示。能靠岸的地方有 4 处：**さくら桟橋**、**漁港**的浮码头、**防波堤**东侧（从堤顶的小平台沿楼梯下到浮码头）、和海湾里的小岛 **凪ノ島**的港口。
- **海有多大**：可以航行的海面东西约 2.9 km、从海滩往外约 1.4 km，远处两个转角是圆的。越接近边界船会越来越慢，最后停在一道看不见的「空气墙」前（提示「ここから先は外洋」），可以顺着它滑行；墙外的大海和远处的海岸线照样一直延伸到天边的雾里。海角以外的海岸线会转向北方，有沙滩、小湾和低矮的山丘。撞到桩子或岸边会「咚」地停下；擦着浮栈桥、码头斜着碰上去时，船会贴着它滑过去而不是卡住。
- **凪ノ島**：约 260 × 180 m 的小岛，北岸是小渔港（岸壁、防波堤臂和红色灯标、停着的渔船、渔具小屋、岛上唯一的小店「なぎの商店」和长椅、邮筒、自动贩卖机），后面的坡上有几户人家；一条 220 m 长、带折返弯的砂石小路（扶手和路灯，路上方的树冠修剪过，不会挡路）通到山顶的白色灯塔和观景台，观景台上的投币望远镜能看到桜ヶ浜的小镇。南侧和东侧是悬崖，种着黑松、杂木和樱花。夜里灯塔会转动光束。
- **水面**：反射天空和夕阳（菲涅耳反射：近处看得到水下的颜色，远处反光更多，但始终保留海水自己的深蓝，傍晚也不会和天空变成一个颜色），栈桥、船和人物在水里有倒影；海浪是几组方向略有不同、被慢慢扭曲的长涌浪加上随风漂移的细波纹，阳光下有闪烁的碎光；浅水处是透明的蓝绿色，越深越蓝，岸边有白色的浪花线。开船时船后拖出 V 字形的航迹和白色的泡沫，船头溅起水花。
- **夜里**：船上挂的马灯会亮，在船边的水面上照出一圈暖光。
- **下雨时**：伞会收起来放在船里。
- **声音**：舷外机的突突声（怠速时一下一下，加速后连成嗡嗡声，有排气和齿轮的声音），水流过船身和船头的嘶嘶声，小浪拍打船板，拉启动绳、熄火、碰撞、系缆的声音，全部程序合成。
- **地图**：在船上（或在岛上）时，地图会换成**海图**：整片海湾、小镇、凪ノ島、4 个能靠岸的地方（锚的标记）和航行范围（虚线）；右上角的小地图在海上会自动放大视野。没坐船时，小地图和地图上会标出小船停在哪里。

- **路**：每一段路面都不一样（山路的蓝色引导线和箭头、山脊的黄色中线、蜜柑园的圆圈纹水泥、梯田的碎石路、鸟居前的石板、隧道里的混凝土）。两边的护栏也按地方换样式：杉林的木栏、山脊和岬角的白色护栏、蜜柑园的镀锌管、茶园和梯田的木桩草绳、竹林的竹栏、鸟居外的石柱玉垣、桥上的朱红栏杆。护栏低而通透，不挡视线，同时把山路上的活动范围限定在路上（休息台和路口留了缺口）。
- **地形是为路修出来的**：路面水平，两侧按挖方 / 填方的坡度过渡；两条路上下贴得太近、放不下坡的地方修了带排水孔的挡土墙；最大坡度约 7%，适合骑车。海岸两头的铁路和公路隧道口保持原样，骑行道从洞门的翼墙旁边经过。
- **路标**：每一段的起点有木牌写着段名，每 500 m 有一根公里桩；驿站的导览图可以按 E 查看整条路线。
- **计时**：骑车向东穿过 START / GOAL 拱门开始计时，依次经过渔港、风车之丘、千本鸟居、隧道和灯塔五个检查点，再穿过拱门就记一圈；右上角显示用时和检查点，最佳成绩记在手帐里（只保存在这台浏览器上）。
- **声音**：溪流和瀑布的水声、竹林的沙沙声和竹子相碰的「咔」声、风车转动的呼呼声、梯田的蛙鸣（白天零星、夜里成片）、田野上空的云雀、渔港的海鸥和拍打码头的海水、隧道里的滴水回声；高原上的风也更大。
- **夜里**：溪谷、梯田和桜川上游有萤火虫一闪一闪；鸟居旁的石灯笼、隧道里的小灯和灯塔的光束都会亮起来。

## 雨天

天气会自己变：开着菜单「天气」里的「ときどき雨が降る」（默认开）时，晴天过几个小时（游戏时间）就可能下雨，有**小雨、雨、大雨**三种，一阵雨下一两个到四五个小时（大雨来得快去得也快）。随机的天气跟着游戏里的时钟走，关掉「时间流动」天气也就停在那里。也可以随时手动：按 `R`、手柄十字键下，或者在菜单「天气」里点 晴 / 雨（手动的雨来得更快）。

- **天空**：先是云层聚起来，天空、云、海都变成灰色，太阳躲进云里，影子淡掉；雨越大远处越白蒙蒙，远山先看不见；夜里没有星星和月亮。
- **雨**：雨丝跟着镜头，但在世界里是固定的（走过去不会跟着跑）；落到地面、屋顶和海面上溅起小水圈。**屋檐下、站台和车站雨棚下、桥下、隧道和屋里都不下雨**——加载时从正上方把整个小镇画了一张「高度图」，雨丝、水花和地面的湿润都以它为准（树叶不算，雨会穿过树冠）。
- **湿的街道**：路面、屋顶、地面变暗、颜色变深，反射灰色的天空；平的地方慢慢积起水洼，雨点在水洼里打出一圈圈涟漪；夜里路灯的光倒映在湿路面上（越远越淡，没有硬边）、被雨点打碎。雨停之后地面要过一阵才干。
- **雨后的彩虹**：雨停的时候如果太阳还不高（上午或傍晚），背对太阳的天空会出现一道彩虹（外红内紫，外侧还有一道淡淡的副虹），慢慢淡去。
- **ななみ的透明伞（ビニール傘）**：雨一下她就把伞举起来撑开；八根伞骨、可以滑动的伞巢和支撑杆、J 形伞柄，伞面是透明的塑料，下雨时上面挂满水珠，伞骨尖上会往下滴水，边缘有一圈白色包边。走路时伞跟着手上下晃，跑起来会往前倾挡雨。走进屋檐下、车站、店里，她会把伞收起来拿在手里（伞挂在手上晃）；参拜的时候也会先收伞；骑车时伞插在车筐里；雨停了就收起来。
  - 动作资源里没有撑伞的动作，所以撑伞的姿势是**程序生成的**：右手用两段 IK 放到胸前，手指握住伞柄、大拇指顺着伞杆，伞杆斜靠向头顶，叠加在原有的走路 / 站立 / 坐下等动作上。
- **镇上的人**：路人也会撑伞（大多是透明伞，也有藏青、黑、米色、粉色等），不再边走边看手机；慢跑的人、骑车的学生和坐长椅的人会回家。芽衣撑一把淡樱色的伞，心愛撑一把带透明小窗的黄色儿童伞。
- **声音**：沙沙的雨声，大雨时还有低沉的轰鸣；身边的雨滴声；撑伞时头顶塑料伞面上细碎的「啪嗒啪嗒」；在屋檐下能听到滴水，进了屋里雨声变闷；湿路面上的脚步带水声，自行车轮胎会「嘶嘶」作响；大雨时远处偶尔打雷；下雨时鸟不叫了，雨蛙（アマガエル）白天也会叫。
- 右上角时钟旁边会出现一个小伞的图标。加 `?rain`（或 `?rain=drizzle` / `?rain=heavy`）可以一打开就是雨天。

## 镇上的人：芽衣

桜坂东侧的人行道上，有一位居民「芽衣」——桜ヶ浜高校二年级的学生，从早上 6:30 到傍晚 19:00 都在坡道上：

- **她的一天**：沿着樱花树下的人行道来回散步（经过行道树时往路边让一让），有时**边走边看手机**（单手拿着，低头看屏幕；这时要走得很近她才会注意到你）；走到路的尽头会停下来做点事——看手机（双手捧着粉色手机打字）、在朝海的一端**手搭凉棚眺望大海**、回头看看、左右换脚站着、伸懒腰、早上打哈欠、抬头看樱花、发呆；有时走到矮墙前的**长椅**坐一会儿，坐着时会时不时**晃晃脚**，再起身继续走。待机是 Mixamo 的 Idle - Female。天黑后她回家了，第二天早上再出现（都发生在你看不见的时候）。
- **和你的互动**：你靠近时她停下、转身看着你；第一次见面会**鞠躬**说「あ、こんにちは。」，之后再见面改成举手打招呼「あ、また会いましたね。」；按 E 聊天，8 个话题轮流出现，每个都有对应的动作和表情——自我介绍时害羞地移开视线、抬头看樱花、开心地讲摄影社、**转身为你指向海边**、说到数学考试时肩膀一垮、推荐神社和澡堂时点头附和、说「有人搭话很开心」时手按在胸口；你跑着撞到她会吓一跳；离开时挥手说「またね」。她坐在长椅上时也能聊天，你还可以坐到她旁边。
- **动作**：来自 Mixamo 动作库（X Bot 骨骼），用 `tools/anim/mixamo.mjs` 重定向到 VRM 骨骼上（含手指）：四肢和手指按骨骼方向在 Mixamo 的 T-pose 上校准，躯干、脖子和头按相对 T-pose 的转动换算（X Bot 的头顶骨点比头部关节靠前约 19°，按方向对齐会让人一直低着头）。原地走路的速度由「着地脚向后滑的速度」算出，人物移动和脚步严格同步，不会滑步。走路是 Female Walk，鞠躬是真人动捕的 Quick Formal Bow，聊天的反应动作来自库里的 Dialogue 类；库里没有的是合成的：**指路**（食指伸出、其余手指握起）和**被吓一跳**。蹲姿类的片段（指向、说话、惊讶等）和裙装不搭，没有使用；坐姿统一调整为**并膝、双手放在腿上**，坐下时裙摆的物理也会改为向前搭在腿上。
- **叠加的细节**：头和眼睛转向你（VRM 视线）、随机眨眼、微笑 / 担心 / 惊讶的表情（微笑和担心是瘦身脚本用 VRoid 的嘴型和眉形另组的表情，说话时眼睛保持睁开，不会像预设的 happy 那样眯成弯月）、说话时按语音音量在「あ・お・え」之间变化口型、头发和衣服的物理摆动（VRM spring bone）、在坡道上用双骨骼 IK 让两只脚各自踩在地面上。配音为 VOICEVOX:四国めたん。
- **画风统一**：人物不用模型自带的 MToon 着色，而是用小镇同一套卡通光照（硬明暗交界、按材质的阴影色、细轮廓光、大气透视、描边）；睫毛、眉毛、虹膜等半透明部分按模型的设置混合绘制。

## 公园里的小女孩：心愛

ひだまり公园里有一位小学三年级的女孩「雪見 心愛（ここあ）」，从早上 8:00 玩到傍晚 5 点的町内广播响过之后（17:06 左右回家，都发生在你看不见的时候）：

- **她的一天**：在游乐设施之间转圈——秋千前、滑梯的出口、沙坑边、熊猫摇摇马、长椅旁，每到一处停下来做点什么：开心地蹦跶、抬头看樱花、东张西望、指着什么东西、左右晃身体、回头看、挥手；有三分之一的时候是**小跑**着去下一个地方；有时坐到长椅上，**两只脚悬空晃来晃去**。
- **和你的互动**：你靠近时她转身看着你，第一次见面**挥手**说「あっ、こんにちは！」，之后再见面是开心地说「あっ、おねえちゃん！また来てくれたの？」；按 E 聊天，8 个话题：自我介绍、接住花瓣许愿（抬头看樱花）、沙坑里睡午觉的猫（指过去）、夸你的自行车（她也刚学会不用辅助轮骑车）、粉色的贝壳宝物、今天的点心是不是布丁（歪头想）、五点钟声一响就得回家（垂头丧气）、「またあそぼうね！やくそくだよ！」；你跑着撞到她会吓一跳；离开时挥手「ばいばーい！またね！」。
- **配音**：**VOICEVOX:春歌ナナ**。选声音时比较了几个童声角色：同一句台词测得的平均音高，東北きりたん（官方设定 11 岁）约 240 Hz、満別花丸约 312 Hz、あいえるたん约 353 Hz、春歌ナナ约 353 Hz；芽衣（四国めたん）是 324 Hz。为了让她听起来明显比高中生的芽衣小，选了音高更高、常被描述为「小女孩」的春歌ナナ，语气预设是语速稍快、抑扬更大的「child」。
- 她和芽衣是同一套居民逻辑（`src/world/residents.js` 的 `RESIDENTS`）：模型、出门时间、台词、手势、散步路线各自配置；路人会给她让路，电车、自行车也会注意她。

## 路人

镇上有 **34 位路人**，用 9 个底模（水手服 / 西装外套两套校服的女生和男生、四位穿便服的女性、一位穿便服的男性）。每个人的打扮都不一样：发色只用黑色和棕色系，校服保持原样，便服的上衣、下装、连衣裙按洗牌后的颜色组合分配，**不会有两个人完全一样**。

- **在路上散步（16 人）**：路线是从镇上的道路数据自动生成的**步行路网**，包括人行道、没有人行道的路边、河边步道的两侧、路口的拐角和过马路，共 600 多段。每个人在自己家附近的街区里**随机漫步**：到路口时随机选方向（直走的可能性更大，过马路少一些），走到尽头往回走，偶尔中途停下来四处看看、看手机，或者改主意掉头。走路的速度每个人、每段都略有不同。
- **慢跑（2 人）**：早上 6～9 点、傍晚 16～19:30 在桜川两岸的步道上跑。
- **骑自行车（5 人）**：学生骑车上下学，路线是 東町通り、桜坂、桜橋通り、西边的町道，还有一位男性在中央二丁目。自行车是带车筐、后货架、挡泥板和链罩的「ママチャリ」，车轮和脚踏会转。人物坐在车座上，用 IK 让**双脚踩在转动的脚踏上、双手握住车把**，手指握拳。转弯时车身向内倾斜；上下坡时车身跟着路面倾斜，**前后轮都贴着地面**。前面有行人时往路中间绕过去；你挡在前面时会刹车停下，左脚放到地上撑住。
- **站着聊天（3 组）**：校门里面的学生、车站前的两位女生、中央广场喷泉旁的两位女性。一人说话（带手势），其他人看着她听、偶尔点头，有时大家一起笑着晃一晃。
- **等公交（2 人）**、**坐长椅（2 人）**：长椅只占一半，你还可以坐在另一半。
- **不乱走、不穿模**：生成路网时每隔 25 cm 检查一次，避开墙和障碍物（挡住时侧身绕过，绕不过去就断开），避开河道里的水面（桥上可以走）和突然的高差；走的时候每一步再检查一次。路人之间、路人和你、和芽衣之间会预判对方的走向，提前侧身让开，没地方让就停下等，一直被挡着就掉头。任何一步都不会让自己离别人更近（距离小于 0.55 m 时）。模拟 4 分钟：进墙 0 次、进水 0 次、两人贴身穿过 0 次、卡住 0 次。
- **作息（晚上人少）**：学生大约 7:00～18:30 在外面；其他人大多在 18:30～19:50 之间陆续回家（每个人的时间前后差 ±25 分钟，不会同时消失），天黑后只剩从车站走回家的两三个人和等末班公交的人，21:30 以后只有一个晚归的人，午夜到清晨 6 点街上没有路人，早上再陆续出门。出门和回家都发生在你看不见的地方：在你身后、视野外或 45 m 以外；如果游戏一开始就是夜里，不在作息时间的人一开始就不会出现。聊天的一组人一起来、一起走。实测：白天约 30 人，19:00 约 17 人，20:00 约 3 人，22:00 1 人，0:00～6:00 0 人。
- **性能**：同一个底模的多个人共用网格和贴图（各自有骨骼和头发物理）；25 m 外降低更新频率并且不算头发物理，30 m 外不投射阴影，75 m 外（骑车的 90 m）不绘制。模型从离你最近的开始，在主角和芽衣之后逐个在后台加载。
- **换色方法**：头发、衣服的贴图在着色器里按「原贴图的明暗 ÷ 贴图亮度的中位数 × 新颜色」重新上色，保留褶皱、条纹和高光；女路人4 的连衣裙只换粉色部分，白色蕾丝保持不变。
- **动作**：女性用 Female Walk，男性用 Mixamo 的 Walking；男性待机是 Breathing Idle、Idle - Weight Shift、Idle Looking Around；慢跑是 Jogging；聊天用 Talking - Funny、Hand Raising、Thinking、Agreeing、Acknowledging、Head Nod Yes（都是站姿；库里的 Talking 是蹲着的，所以没有用）。骑车没有现成动作，是程序生成的姿势。
- 新的组合只要在 `src/world/pedestrians.js` 的 `PEOPLE` 里加一行（模型、做什么、在哪里）。

## 渲染风格 / Rendering

- **卡通着色**：自定义 `ShaderMaterial`（接入 three.js 的阴影），硬明暗交界线 + 偏紫蓝的阴影色 + 交界处的暖色带，模仿动画背景的上色方式。阴影面像画师调色那样「保留并略微提高固有色的饱和度」，不会变成发灰的脏色；受光面里天空补光的比例降低，让阳光主导、受光面保持暖而通透；阴影的色相随时间段变化（白天偏冷蓝、傍晚偏紫）。
- **程序化表面细节**：外墙挂板、瓦片、水泥砌块、砖、沥青、沙、草地上的小花等都在着色器里按世界坐标生成，并做了抗锯齿与远处淡出。
- **描边**：后处理中对深度做拉普拉斯检测，只在靠近相机的一侧画线，线色是底色的加深版，并随距离淡出；离镜头 5〜16 m 以内额外用 2 像素半径再检测一次，近处的轮廓线更粗、远处更细，像手绘线条一样有轻重。
- **角落的「影溜まり」**：只用深度就能找出凹进去的折角——墙脚与地面相接处、屋檐下、长椅下、柱子根部。做法是在像素上下成对取样（约 0.55 m 的世界距离、12 个半径，不加逐像素抖动：那种抖动固定在屏幕上，镜头一动就像阴影在闪），1/z 在任何平面上都是线性的，所以平整的墙和路上一对样本正好抵消，只有凹角会「落在两边的后面」；碰到前面很远的物体（那是轮廓而不是折角）的样本对直接跳过，所以不会在电线杆、招牌周围出现一圈黑晕。阴影色偏冷蓝，140 m 外淡出，草和树冠里基本不加。
- **柔光（ディフュージョン）**：把画面缩到 1/8〜1/32 分辨率做多级模糊，只取亮部，主要在「模糊后比原图更亮」的地方叠加——天空和被晒亮的墙会把光晕溢到树冠、屋顶、电线杆的边缘上（动画摄影里的柔光滤镜效果），平整的大面积区域只加一点点，墙面和室内不会发白。
- **光柱与漏光**：面向太阳时，1/4 分辨率下从每个像素向太阳在屏幕上的位置（包括刚出画面的位置）步进，统计经过多少「露天」，在树枝、屋顶、电线杆的缝隙之间形成放射状光柱，傍晚最明显；太阳一侧的画面边缘还会渗进一层暖色漏光（白天淡金色，日落时橙色）。
- **画面上下的渐变（パラ）**：画面上方的天空向天顶加深，脚下的地面略微压暗，把视线引到中景；进入室内或地下时这些天空渐变和漏光会自动退掉。
- **天空**：渐变天空 + 刷痕状卷云（更细、更通透，不再是一层灰纱）+ 程序化绘制的平底积云贴片 + 天穹上的积云改为「受光面 / 背光面」两层色调 + 远山与富士山剪影 + 星空和月亮。
- **樱花树冠**：每一团花簇只取一种颜色（卡片之间只差一点点），卡片只做小角度旋转，让贴图里画好的高光始终在上方，光照按「整团」计算；阴影在卡片中心附近、并朝光源方向抬高一些后查询，屋顶或别的树冠投下的影子会沿着花团的形状落下，而不是一刀直线切过树冠，外层花簇也不会被旁边的卡片误遮成暗色。花瓣有一点透光，从树下往上看时，树冠底面仍带着粉色的亮度。
- **角色逆光**：太阳在人物背后时，头发和肩膀的轮廓会亮起一圈逆光边。
- **调色**：按时间段的调色表（阴影色、受光面补光、角落阴影色、柔光强度、天空渐变、阴影/高光的分离色调、漏光、光柱），外加自然饱和度（偏灰的颜色多加一点、本来就鲜艳的少加）、轻微的 S 曲线、暗角与纸张颗粒；大气透视比以前略浓，远处的街区一层层变淡变蓝。
- **画质**：「低」画质（手机默认）会关闭角落阴影和光柱，其余效果保留。
- **人物的光**：在室内（商店、医院、学校、地铁）人物改用房间顶灯的柔和光照，不再沿用天空和月光；夜里在室外，人物的光保留大部分亮度、去掉偏蓝的色调，肤色和衣服的颜色不会变灰变蓝。
- **天花板不闪**：室内材质在深度上稍微靠前一点，房间天花板和上面楼体外壳的底面在同一高度时（医院、商场等），从室内看始终是天花板，不会两层交替闪烁。
- **泛光、镜头光晕**，以及 three.js r186 的 `SunLight` 级联阴影。
- 昼夜循环（默认 1 分钟 = 1 小时）：夜里窗户、路灯、自贩机、灯笼会亮。路灯的光由着色器逐像素计算，照在地面、墙、栏杆、草叶和树冠上，光圈边缘柔和地淡出，不会被坡道和路缘切成一块块；屋外的路灯照不进屋檐下（店里），门廊灯这类檐下的灯只照檐下。
- **绿化**：树冠、树篱、灌木、花坛共用一套朝向相机的叶片卡片（Canvas 现场绘制的叶子 / 五瓣樱花 / 杜鹃花），树篱是叶片包裹的暗色内层，不再是绿色方块；草坪、路边、铁道边坡和山脚长着随风摆动的草丛（按 32 m 分块实例化，只绘制镜头附近）。树冠会自动避开建筑。
- **叶子不穿墙**：建造小镇时把每一块墙、柱、栏杆、楼板记下来，所有叶片卡片建好后统一检查一遍——贴着墙的叶片往外推、必要时缩小（最多缩到 0.6 倍），整片陷在厚实体里的叶片直接去掉（约 9.7 万片里移动约 4,400 片、去掉约 150 片）。地址加 `?nofit` 可以关掉对比。
- **阴影不闪**：three.js r186 的 PCF 软阴影按屏幕像素随机旋转采样（为 TAA 设计），没有 TAA 时镜头或太阳一动，阴影边缘就会闪；这里改成固定的 3×3 采样网格，并修正了反向深度下阴影偏移方向反了的问题（以前墙面会有自阴影条纹）。实测镜头微动时闪烁的像素从 1.54% 降到 0.25%。
- **远处不闪烁**：深度缓冲改用反向 Z（浮点深度，远处精度不再不够，远处建筑不会互相「打架」闪烁），近裁剪面调到 0.15 m；招牌、栅栏网这类镂空贴图用 alpha-to-coverage 抗锯齿；描边在 200 m 外淡出。显卡不支持反向 Z 时自动退回普通深度。

## 碰撞与「不穿模」

- 2D 空间哈希碰撞 + 可分层的行走面（桥面、站台、地下一二层、商场二楼可以上下叠放，按脚的高度判定所在楼层）。
- 河堤顶、桥头、踏切的抬高路面、飞石都有对应的行走面；不能下到有护岸的河道里涉水（河口沙滩处可以）。飞石两岸楼梯的顶部平台朝上游的一端也装了栏杆（以前从那里跳下去会落到落差工的斜面上，四周是水、爬不回来）。
- 车道和人行道画在地形上方 3 cm，行走面也按这个高度算（以前轮胎和鞋底会陷进路面 3 cm）。
- 学校操场四周都围上了：靠山的北侧在防球网下面补了一道铁栅栏、网和立柱都有碰撞，操场唯一的入口是校舍前院穿过挡土墙的台阶。
- 坐下和站起：起身时从座位正前方走出来（被挡住就从侧面），不会跑到长椅后面的墙里；拉面店等**柜台座位**会坐得靠后一点，膝盖和小腿不穿进柜台。居民回家后不再显示「和她聊聊」的提示。
- 电车车身、海岸路上的汽车、放下的踏切栏杆都是会移动的碰撞体；站在轨道或车道上，电车和汽车会停下。
- 停在坡上的车按四个轮子的位置倾斜，自动贩卖机、太阳能板、墙头的猫都贴合各自的表面。
- 坡地上的建筑：公寓的外楼梯、走廊立柱、房屋的雨水管、汐の湯的门廊柱、铁栅栏（带混凝土基座）都从各自位置的地面往上长，不会因为地基比地面高而悬空。
- 悬空自检：地址加 `?audit` 会记录所有长方体和圆柱，页面里的检查脚本能列出「底部离地、下面又没有东西托着」的立柱 / 栏杆 / 墙段（调试用，默认关闭）。
- 学校的四层楼是叠放的行走面（每层按脚的高度生效），折返楼梯一级一级都有对应高度；病院、邮局门前地面比室内低的地方加了平台和台阶。
- 自动化测试脚本（Playwright）模拟玩家走进便利店 / 咖啡馆 / 图书馆 / 商场二楼、下地铁到站台、踩飞石过河、过每一座桥，从校门走到教室、爬楼梯上屋顶、穿连廊进体育馆、上操场，进出医院 / 邮局 / 交番 / 钱汤（男汤进不去、浴池边沿挡得住），以及电车在有人时的停车距离，用来检查卡住和掉落。

## 声音 / Audio

环境声全部用 Web Audio 合成：海浪、河水与落差工的水声、风、麻雀、树莺（ホーホケキョ）、海边的黑鸢（ピーヒョロロ）、夜晚的蛙鸣、风铃、踏切警报、红绿灯的盲人提示音（ピヨピヨ / カッコー）、便利店开门铃、地铁广播与到站旋律、电车（行驶声、轨缝声、鸣笛、发车旋律）、脚步声（沥青 / 沙 / 浅水），以及随时间段变化的生成式背景音乐。进入室内或地下时环境声会变闷。

**背景音乐（三段，随时间自动切换）**：全部实时合成、边弹边作曲。每 8 小节一个乐句，开头会随机选一条和弦进行、一种编配（哪些乐器出场、多密），有旋律的乐句由一个动机和它的变奏现编（强拍落在和弦音上，弱拍用不和和弦打架的经过音，以级进为主、跳进之后反向回落），所以几乎不会原样重复。时间到了，上一段停止落新音、在余音里淡出，下一段在几秒后淡入。

| 时间段 | 曲子 | 调 / 速度 | 乐器与特点 |
| --- | --- | --- | --- |
| 清晨〜白天（4:54–16:24） | 小镇的钢琴（原来那首） | D 大调，68 BPM | 「王道进行」IV–V–iii–vi，分解和弦加稀疏的旋律 |
| 黄昏（16:24–19:18） | **夕凪** | F 大调，63 BPM | 电钢琴（缓慢左右摇摆）、弦乐铺底、圆润的贝斯，部分乐句有柔和的笛声旋律；5 条和弦进行，含借用的 iv（B♭m6），带一点夕阳下的怀旧和惆怅 |
| 夜晚（19:18–4:54） | **夜の海** | D♭ 大调（偏 Lydian），56 BPM | 暗色长音铺底、像星星一样一颗颗出现的八音盒（左右回声）、低音区轻柔的钢琴应答，偶尔几句慢旋律；也有只剩铺底的「呼吸」乐句 |

**不卡顿**：
- 音符提前 1.8 秒排进音频线程，页面偶尔卡一下（后台加载路人模型、第一次编译着色器）也不会打断音乐；卡得更久时，错过的音符直接跳过，不会恢复时一下子全部挤出来。
- 踏切的钟声、电车过轨缝、红绿灯提示音、青蛙的合唱按**音频时钟**提前排好，不再跟着画面帧计时：画面掉帧时，节奏也不会快一下慢一下（主线程故意卡住 250 ms 的测试中，钟声间隔从 0.49〜0.73 s 波动变为恒定 0.52 s）。
- 反复出现的短音（钟声、轨缝声、提示音、青蛙、各种地面的脚步声）启动时在离线音频线程里「烘焙」成缓冲，每次播放只需 1〜2 个节点，原来要 3〜25 个；雨声改为预先渲染的循环层（地面和伞面各两层，长度不同，叠在一起不会听出循环），不再每颗雨滴新建节点。每秒新建的音频节点：雨天约 121 → 5，夜里镇上约 47 → 2，夜里的稻田约 95 → 1。
- 音频缓冲取 80 ms（比浏览器默认的最低延迟大一些），画面负载高时不容易爆音；每帧更新的音量、频率只有真正变化时才写进音频线程。
